# Converter+

Приложение для Windows 10/11, которое конвертирует и сжимает популярные форматы файлов. Интерфейс доступен на русском и английском; режим «Автоматически» следует языку Windows, выбирая русский только для русской системы. Для конечного пользователя приложение и FFmpeg упакованы вместе с .NET: ставить Python или .NET отдельно не нужно.

## Установка

Запустите `release/ConverterPlus-Setup-1.0.2.exe`, завершите установку и откройте Converter+ из меню «Пуск». После каждой установки приложение один раз показывает приветствие и сохраняет остальные настройки пользователя; при повторной установке текст приветствия меняется. Перетащите файлы в окно, выберите формат для каждого и нажмите Convert. По умолчанию файлы конвертации сохраняются в `Документы\Converter+\Converter`, а результаты сжатия — в `Документы\Converter+\Compression`. Для каждого режима можно выбрать свою папку. Существующие файлы не перезаписываются.

Для конвертации Word, Excel, PowerPoint и PDF в офисные форматы нужен бесплатный LibreOffice. Приложение само покажет кнопку загрузки, если LibreOffice не найден. Конвертация изображений, аудио и видео не требует дополнительных установок.

## Поддерживаемые форматы

- Изображения: PNG, JPG, WebP, BMP, TIFF, GIF, ICO, AVIF и HEIC. Поддержка отдельных форматов зависит от кодеков Magick.NET.
- Аудио: MP3, WAV, FLAC, AAC, M4A, OGG, Opus, WMA.
- Видео: MP4, MKV, MOV, WebM, AVI, WMV, MPEG.
- Документы: DOC, DOCX, ODT, RTF, TXT, HTML, XLS, XLSX, ODS, CSV, PPT, PPTX, ODP, PDF. Конвертация офисных файлов выполняется через LibreOffice.

## Сборка установщика

Для разработчика нужны Windows x64, .NET SDK 10 и Inno Setup 6. Запустите `build.ps1` в PowerShell. Скрипт загрузит LGPL shared-сборку FFmpeg, опубликует приложение автономно и создаст `release/ConverterPlus-Setup-1.0.2.exe`. Установщик не подписан цифровым сертификатом, поэтому Windows может показать предупреждение издателя.
